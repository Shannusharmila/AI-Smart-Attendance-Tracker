# AI-Based Smart Attendance Tracker — VS Code source files

This folder contains **114 source/configuration files** extracted from the uploaded
`ai-smart-attendance-tracker-full-code(4).txt`.

## Important: use this as an overlay on your existing project

1. Close the running Next.js terminal (`Ctrl + C`) if it is running.
2. In File Explorer, open your existing `AI-Smart-Attendance-Tracker` project folder.
3. Extract this ZIP **into that existing project folder** (not into `src`).
4. If Windows asks whether to replace files such as `package.json`, `next.config.ts`,
   or files under `src`, choose **Replace the files in the destination**.
5. Do not copy the ZIP into `node_modules`. Do not delete `node_modules` yet.
6. In VS Code, choose **File → Open Folder** and open the existing
   `AI-Smart-Attendance-Tracker` folder.

The ZIP preserves the source paths. For example:
- `prisma/schema.prisma` is a file inside the `prisma` folder.
- `src/app/api/auth/login/route.ts` is a file inside the nested
  `src → app → api → auth → login` folders.
- `src/components/teacher/take-attendance.tsx` is a file inside the
  `src → components → teacher` folders.

## One required step: generate the UI component files

The uploaded text lists the shadcn/ui components but does **not** include their
individual source code. The application imports these 16 UI primitives:

```powershell
npx shadcn@latest add alert-dialog badge button card dialog input label select sheet slider sonner switch table tabs textarea toast
```

Run that command in the VS Code terminal from the project root. If prompted to overwrite
an existing UI component, review the prompt and choose the option that keeps the
generated component setup consistent.

## Install and run with Node.js / npm on Windows

Open **Terminal → New Terminal** in VS Code. Make sure the terminal path ends with
`AI-Smart-Attendance-Tracker`, then run these commands one at a time:

```powershell
npm install
```

```powershell
Copy-Item .env.example .env
```

If `.env` already exists, do not overwrite it; check that it contains:

```env
DATABASE_URL="file:./dev.db"
```

Then run:

```powershell
npx prisma generate
```

```powershell
npm run db:push
```

```powershell
npm run db:seed
```

```powershell
npm run dev
```

Open `http://localhost:3000` in your browser.

## Notes

- The package scripts were made Windows/npm-friendly. Application source files were extracted
  from the uploaded text file.
- The source describes the AI face-recognition and GPS verification endpoints as demo/simulated
  functionality; do not treat them as production biometric/GPS verification.
- `components/ui` primitives are generated by the shadcn command above because their full
  implementations were not included in the uploaded text.
- The `.env` section in the uploaded source was blank, so `.env.example` is provided instead.
- Keep your existing `node_modules` folder; `npm install` will reconcile dependencies.
